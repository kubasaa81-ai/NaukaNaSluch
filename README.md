# Nauka na słuch

Aplikacja na Androida do nauki ze słuchu: lektor czyta PDF / TXT / wklejony tekst, tryb zakrywania tekstu, „Powtarzaj za mną”, test z odpowiedziami na głos. Odtwarza też audiobooki. Działa bez internetu i bez konta.

**Pobierz APK:** zakładka *Releases* → „najnowsza” → `NaukaNaSluch.apk`.
